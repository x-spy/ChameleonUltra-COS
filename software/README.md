# ChameleonUltra-COS CLI

This directory contains the Python CLI and supporting native tools inherited from Chameleon Ultra, with additional commands for ChameleonUltra-COS.

COS-related CLI commands are third-party fork extensions. They are not official upstream Chameleon Ultra commands unless and until they are independently accepted upstream.

## Package Management

The upstream project uses `uv` for package management. This fork keeps that direction where applicable.

Reference: https://docs.astral.sh/uv/

## Safety

Do not use the CLI to upload, store, export, or share real production card dumps, keys, secrets, credentials, personal data, or protected system data.

Use COS commands only with cards, readers, data, and systems you own or are authorized to test.
