# Support

ChameleonUltra-COS is an unofficial third-party fork.

## Where to Ask

Use this repository's issues for fork-specific problems, especially:

- COS emulation behavior.
- COS CLI commands.
- COS storage and APDU handling.
- Documentation in this fork.

Do not ask upstream Chameleon Ultra maintainers or official communities to support fork-specific changes unless the issue is reproduced in the unmodified upstream project.

## What Not to Ask For

Support will not be provided for:

- Unauthorized access, credential cloning, or bypassing payment/fare/access-control systems.
- Real production card dumps, keys, secrets, protected data, or personal data.
- Circumvention of laws, contracts, terms of service, or technical protection measures.

## Before Opening an Issue

- Check [README.md](README.md), [DISCLAIMER.md](DISCLAIMER.md), [NOTICE.md](NOTICE.md), and [SECURITY.md](SECURITY.md).
- Confirm the issue is reproducible on this fork.
- Include commit hashes, device model, CLI version, firmware version, and synthetic reproduction data.
