# Authors and Contributors

Copyright for each contribution is tracked by Git history.

For this fork, use:

```bash
git shortlog -nse
```

To inspect contribution history for a specific file:

```bash
git log --pretty=short --follow <path/to/sourcefile> | git shortlog -ne
```

This repository preserves the upstream Chameleon Ultra history. Upstream contributors remain credited through Git history and upstream project records:

- Upstream repository: https://github.com/RfidResearchGroup/ChameleonUltra
- Upstream contributors: https://github.com/RfidResearchGroup/ChameleonUltra/graphs/contributors

Fork-specific contributions are credited in this repository's Git history.
